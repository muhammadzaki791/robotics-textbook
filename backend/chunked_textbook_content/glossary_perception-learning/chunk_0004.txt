

**Dense Depth Estimation**: The process of estimating depth information for every pixel in an image, important for 3D scene understanding. **Depth Camera**: A camera that captures distance information for each pixel, providing 3D information about the scene. **Episodic Memory**: Memory of specific events or experiences, which can be used by robots to learn from past interactions. **Episodic Learning**: Learning that occurs through experience of specific episodes, as opposed to learning from abstract rules. **Exploration vs. Exploitation**: The fundamental trade-off in reinforcement learning between exploring new actions and exploiting known good actions. **Feature Extraction**: The process of identifying relevant characteristics from raw sensor data, crucial for robot perception. **Fiducial Markers**: Artificial visual markers used to aid in robot localization and mapping. **Fisher Information**: A measure of the amount of information that an observable random variable carries about an unknown parameter, used in optimal experiment design. **Generalization**: The ability of a learned model to perform well on new, unseen data, critical for robot deployment in real environments. **Generative Adversarial Network (GAN)**: A machine learning framework with two competing neural networks used for generating realistic data, useful for robot training. **Ground Truth**: The accurate and reliable reference data used to evaluate robot perception and learning systems. **Haptic Feedback**: The use of touch and motion feedback to provide information to a user, important for robot teleoperation and human-robot interaction. **Hierarchical Learning**: A learning approach that organizes knowledge and skills into multiple levels of abstraction, from simple to complex. **Hyperparameter**: A parameter whose value is set before the learning process begins, such as learning rate or network architecture parameters. **Intrinsic Motivation**: Learning driven by internal rewards rather than external rewards, used to enable autonomous learning in robots. **Kernel Methods**: A class of machine learning algorithms that use kernel functions to operate in a high-dimensional space, useful for robot learning. **Learning Rate**: A hyperparameter that controls how much to change the model in response to the estimated error each time the model weights are updated. **Manifold Learning**: A technique for learning low-dimensional representations of high-dimensional data, useful for robot perception and control. **Maximum Likelihood Estimation**: A method for estimating the parameters of a statistical model by maximizing the likelihood function, used in state estimation. **Monte Carlo Methods**: A class of computational algorithms that rely on repeated random sampling, used in reinforcement learning and state estimation.
