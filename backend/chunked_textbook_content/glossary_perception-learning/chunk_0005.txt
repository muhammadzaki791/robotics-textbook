**Multi-Task Learning**: A learning approach where a model learns to perform multiple related tasks simultaneously, improving efficiency and generalization. **Optical Flow**: The pattern of apparent motion of objects, surfaces, and edges in a visual scene caused by the relative motion between an observer and the scene. **Overfitting**: A modeling error in machine learning where a function is too closely fit to a limited set of data points, reducing generalization ability. **Perceptual Aliasing**: When different states appear identical to a robot's sensors, causing problems in state estimation and learning. **Policy Gradient**: A class of reinforcement learning algorithms that directly optimize the policy parameters to maximize expected reward. **Probabilistic Robotics**: An approach that explicitly represents and handles uncertainty in robot perception and control using probability theory. **Proximal Policy Optimization (PPO)**: A policy gradient method in reinforcement learning that uses a clipped objective function to improve stability. **Recurrent Neural Network (RNN)**: A type of neural network designed to handle sequential data, useful for robot learning with temporal dependencies. **Regularization**: Techniques used to prevent overfitting in machine learning models by adding constraints or penalties. **Representation Learning**: Learning to automatically discover the representations needed for feature detection or classification from raw data. **Robot Operating System (ROS)**: A flexible framework for writing robot software that provides services designed for a heterogeneous computer cluster. **Scene Understanding**: The process of interpreting and understanding the content of a visual scene, including object recognition and spatial relationships. **Self-Supervised Learning**: A learning approach where the training data is automatically generated from the input data itself, useful for robot learning with limited supervision. **Semantic Segmentation**: The process of assigning a class label to each pixel in an image, enabling detailed scene understanding. **Sensor Calibration**: The process of determining and correcting sensor errors to ensure accurate measurements. **Sim-to-Real Transfer**: The process of transferring skills learned in simulation to real robots, a major challenge in robotics. **Slam (Simultaneous Localization and Mapping)**: The computational problem of constructing or updating a map of an unknown environment while simultaneously keeping track of an agent's location. **Sparse Coding**: A representation learning technique that represents data as a sparse combination of basis functions, useful for efficient robot learning. **State Representation Learning**: Learning compact and meaningful representations of the environment state for robot learning and control.
