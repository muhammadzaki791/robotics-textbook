# RAG Chatbot Frontend

Frontend for the RAG (Retrieval Augmented Generation) chatbot integrated with the Physical AI & Humanoid Robotics textbook.

## Overview

This React-based frontend provides:
- Chatbot widget for textbook Q&A
- Text selection detection for selected-text mode
- Responsive design for textbook integration
- API integration with the backend service

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Architecture

- React for UI components
- Webpack for bundling
- Babel for JavaScript transpilation
- CSS for styling
- Axios for API communication
