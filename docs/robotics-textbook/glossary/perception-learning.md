# Perception and Learning

**Computer Vision**: A field of artificial intelligence that trains computers to interpret and understand the visual world, enabling robots to recognize objects, people, and environments.

**Convolutional Neural Network (CNN)**: A type of deep learning neural network particularly effective for image recognition and computer vision tasks.

**Deep Learning**: A subset of machine learning that uses neural networks with multiple layers to model and understand complex patterns in data.

**Deep Reinforcement Learning**: The combination of deep learning and reinforcement learning, using neural networks to approximate value functions or policies in reinforcement learning problems.

**Reinforcement Learning**: A type of machine learning where an agent learns to make decisions by taking actions in an environment to maximize cumulative reward.

**Supervised Learning**: A machine learning approach where the algorithm learns from labeled training data, with input-output pairs provided by a supervisor.

**Unsupervised Learning**: A type of machine learning where the algorithm learns patterns from data without labeled examples.

**Neural Network**: A computing system inspired by the human brain, consisting of interconnected nodes that can learn to recognize patterns and make decisions, fundamental to modern AI.

**State Estimation**: The process of determining the internal state of a system from noisy and partial observations, fundamental to robot perception and control.

**Sensor Fusion**: The process of combining data from multiple sensors to achieve better performance than any individual sensor could provide.

**LiDAR**: Light Detection and Ranging, a remote sensing method that uses light in the form of a pulsed laser to measure distances, commonly used in robotics for mapping and navigation.

**Point Cloud**: A set of data points in space, typically representing the external surface of an object, commonly generated by 3D scanners and LiDAR sensors.

**Natural Language Processing (NLP)**: A field of AI focused on enabling computers to understand, interpret, and generate human language, important for human-robot communication.

**Imitation Learning**: A machine learning approach where robots learn skills by observing and mimicking expert demonstrations.

**Learning from Demonstration (LfD)**: A method where robots learn tasks by observing human demonstrations, also known as imitation learning.

**Behavioral Cloning**: A machine learning approach in robotics where a robot learns to perform tasks by mimicking expert demonstrations, typically using supervised learning.

**Multi-Modal Learning**: Learning that combines information from multiple sensory modalities (e.g., vision, touch, audio) to improve robot performance.

**Gaussian Process**: A probabilistic machine learning model that can represent uncertainty in predictions, useful for robot learning and control.

**Q-Learning**: A model-free reinforcement learning algorithm that learns a policy telling an agent what action to take under what circumstances.

**Markov Decision Process (MDP)**: A mathematical framework for modeling decision-making in situations where outcomes are partly random and partly under the control of a decision maker, fundamental to reinforcement learning.

**Explainable AI**: AI systems that can explain their reasoning and decision-making processes in human-understandable terms.

**Black Box Problem**: The challenge of understanding how an AI system makes decisions when the internal processes are opaque or difficult to interpret.

**Active Learning**: A machine learning paradigm where the algorithm can query a user or an oracle to obtain new data points, useful for efficient robot learning.

**Actor-Critic Method**: A reinforcement learning approach that combines value-based and policy-based methods, with an actor that learns the policy and a critic that evaluates it.

**Affordance**: The possibility of an action that an object offers to an agent; for example, a handle affords grasping.

**Augmented Reality (AR)**: A technology that overlays digital information onto the real world, increasingly used for robot programming and human-robot interaction.

**Autonomous Learning**: The ability of robots to learn and improve their performance without human intervention.

**Bayesian Inference**: A statistical method that updates the probability of a hypothesis as more evidence becomes available, used in robot perception and decision making.

**Bayesian Optimization**: A sequential optimization technique that uses Bayesian inference to find the minimum or maximum of an objective function, useful for robot learning.

**Biomimetic Learning**: Learning approaches that mimic biological systems, particularly useful for robot locomotion and control.

**Calibration**: The process of adjusting a sensor or system to ensure accurate measurements, critical for robot perception.

**Canonical Correlation Analysis (CCA)**: A statistical method to find correlations between two sets of variables, useful for multi-modal sensor fusion.

**Clustering**: An unsupervised learning technique that groups similar data points together, used for scene understanding and object recognition.

**Convolution**: A mathematical operation that combines two functions to produce a third, fundamental to CNNs and signal processing in robotics.

**Cross-Validation**: A technique for assessing how well a machine learning model will generalize to new data, important for robot learning.

**Data Augmentation**: The process of artificially increasing the size of a training dataset by adding modified versions of existing data, crucial for robot learning with limited data.

**Deep Q-Network (DQN)**: A reinforcement learning algorithm that uses deep neural networks to approximate Q-values, enabling learning from high-dimensional sensory inputs.

**Dense Depth Estimation**: The process of estimating depth information for every pixel in an image, important for 3D scene understanding.

**Depth Camera**: A camera that captures distance information for each pixel, providing 3D information about the scene.

**Episodic Memory**: Memory of specific events or experiences, which can be used by robots to learn from past interactions.

**Episodic Learning**: Learning that occurs through experience of specific episodes, as opposed to learning from abstract rules.

**Exploration vs. Exploitation**: The fundamental trade-off in reinforcement learning between exploring new actions and exploiting known good actions.

**Feature Extraction**: The process of identifying relevant characteristics from raw sensor data, crucial for robot perception.

**Fiducial Markers**: Artificial visual markers used to aid in robot localization and mapping.

**Fisher Information**: A measure of the amount of information that an observable random variable carries about an unknown parameter, used in optimal experiment design.

**Generalization**: The ability of a learned model to perform well on new, unseen data, critical for robot deployment in real environments.

**Generative Adversarial Network (GAN)**: A machine learning framework with two competing neural networks used for generating realistic data, useful for robot training.

**Ground Truth**: The accurate and reliable reference data used to evaluate robot perception and learning systems.

**Haptic Feedback**: The use of touch and motion feedback to provide information to a user, important for robot teleoperation and human-robot interaction.

**Hierarchical Learning**: A learning approach that organizes knowledge and skills into multiple levels of abstraction, from simple to complex.

**Hyperparameter**: A parameter whose value is set before the learning process begins, such as learning rate or network architecture parameters.

**Intrinsic Motivation**: Learning driven by internal rewards rather than external rewards, used to enable autonomous learning in robots.

**Kernel Methods**: A class of machine learning algorithms that use kernel functions to operate in a high-dimensional space, useful for robot learning.

**Learning Rate**: A hyperparameter that controls how much to change the model in response to the estimated error each time the model weights are updated.

**Manifold Learning**: A technique for learning low-dimensional representations of high-dimensional data, useful for robot perception and control.

**Maximum Likelihood Estimation**: A method for estimating the parameters of a statistical model by maximizing the likelihood function, used in state estimation.

**Monte Carlo Methods**: A class of computational algorithms that rely on repeated random sampling, used in reinforcement learning and state estimation.

**Multi-Task Learning**: A learning approach where a model learns to perform multiple related tasks simultaneously, improving efficiency and generalization.

**Optical Flow**: The pattern of apparent motion of objects, surfaces, and edges in a visual scene caused by the relative motion between an observer and the scene.

**Overfitting**: A modeling error in machine learning where a function is too closely fit to a limited set of data points, reducing generalization ability.

**Perceptual Aliasing**: When different states appear identical to a robot's sensors, causing problems in state estimation and learning.

**Policy Gradient**: A class of reinforcement learning algorithms that directly optimize the policy parameters to maximize expected reward.

**Probabilistic Robotics**: An approach that explicitly represents and handles uncertainty in robot perception and control using probability theory.

**Proximal Policy Optimization (PPO)**: A policy gradient method in reinforcement learning that uses a clipped objective function to improve stability.

**Recurrent Neural Network (RNN)**: A type of neural network designed to handle sequential data, useful for robot learning with temporal dependencies.

**Regularization**: Techniques used to prevent overfitting in machine learning models by adding constraints or penalties.

**Representation Learning**: Learning to automatically discover the representations needed for feature detection or classification from raw data.

**Robot Operating System (ROS)**: A flexible framework for writing robot software that provides services designed for a heterogeneous computer cluster.

**Scene Understanding**: The process of interpreting and understanding the content of a visual scene, including object recognition and spatial relationships.

**Self-Supervised Learning**: A learning approach where the training data is automatically generated from the input data itself, useful for robot learning with limited supervision.

**Semantic Segmentation**: The process of assigning a class label to each pixel in an image, enabling detailed scene understanding.

**Sensor Calibration**: The process of determining and correcting sensor errors to ensure accurate measurements.

**Sim-to-Real Transfer**: The process of transferring skills learned in simulation to real robots, a major challenge in robotics.

**Slam (Simultaneous Localization and Mapping)**: The computational problem of constructing or updating a map of an unknown environment while simultaneously keeping track of an agent's location.

**Sparse Coding**: A representation learning technique that represents data as a sparse combination of basis functions, useful for efficient robot learning.

**State Representation Learning**: Learning compact and meaningful representations of the environment state for robot learning and control.

**Stereovision**: The process of extracting 3D information from 2D images captured from different viewpoints, used for depth perception in robots.

**Structured Learning**: Learning methods that predict structured outputs rather than scalar values, useful for robot planning and control.

**Support Vector Machine (SVM)**: A supervised learning model that finds the optimal hyperplane to separate different classes in data.

**Transfer Learning**: A machine learning technique where a model trained for one task is reused as the starting point for a model on a second task.

**Unimodal Learning**: Learning that uses only a single type of sensor data, as opposed to multi-modal learning.

**Variance Reduction**: Techniques used to reduce the variance of estimates in machine learning, particularly important in reinforcement learning.

**Visual Servoing**: The control of robot motion using visual feedback, enabling precise manipulation and navigation.

**Visual-Inertial Odometry**: The combination of visual and inertial measurements to estimate robot motion, providing robust state estimation.

**Zero-Shot Learning**: A learning approach where a model can recognize classes it has never seen during training, useful for robot adaptation.
